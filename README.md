# Health Connect: Healthcare Management API
Health Connect is a secure REST API for medical practices. Manage patients, appointments, and clinical encounters with JWT auth and role-based access control.

# Documentation:
Feel free to check complete documentation [here](https://bletz-9c648faf.mintlify.app/).

Health Connect gives medical practices a fast, secure API to manage everything from patient admissions and appointment scheduling to clinical encounter documentation. Every request is authenticated with a short-lived JWT token, and access is scoped by role — so doctors, receptionists, and administrators each see only what they need.
